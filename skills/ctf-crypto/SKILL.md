# ctf-crypto

## 适用范围与排除

本地密码和数学题分析。排除真实密钥、外部认证尝试。

## 输入与前置检查

输入需注明数据编码、字节序、密文、参数和固定向量。先区分编码、哈希、加密和签名。

## 分析流程

古典密码检查频率和密钥周期。对称题检查模式、IV、nonce、填充。非对称题先列方程、模数与逆元存在条件。哈希检查长度与域分离，签名检查 nonce 复用与校验条件。

## 工具与中间证据

优先考虑已验证的 Python 标准库。当前自动化使用 crypto-local 的固定 XOR 向量。记录参数、输入摘要、中间值摘要及反向结果，保持计算可重放。

## 误判、验证与停止条件

无逆元、输入截断、参数不明时停止猜测。独立反向重编码或重新验签并比对固定预期，格式正确只记 FORMAT_VALID。
